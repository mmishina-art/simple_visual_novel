# サウンドノベル ― 声の出る短編集

本棚から短編小説を選び、文章を読み進め、選択肢で物語が分岐するサウンドノベル集です。全編に読み上げ音声とフリガナが付いていて、読むことも、聴くこともできます。選択次第でハッピーエンドにもバッドエンドにもなります（各冊とも結末は全3通り）。

公開 URL（GitHub Pages）: https://mmishina-art.github.io/simple_visual_novel/
紹介ページ: https://mmishina-art.github.io/simple_visual_novel/home/
※ 公開には GitHub の Settings → Pages → Source を **GitHub Actions** にする設定が必要です（初回のみ）。

## 遊び方

- タイトル画面で「はじめる」を押すと本棚が開きます。読みたい本を選んでください。読みかけの本を選ぶと「つづきから読む／最初から読む」を選べます。
- 本文（背景の上の縦書き）をタップすると文章が進みます。文章は消えずに左へ追加されていき、画面がいっぱいになると、ページをめくるように全部消えて、新しいページが右から始まります。
- 読み上げがオンのときは、場面ごとに音声が流れます。タップで読み上げを飛ばせます。音・読み上げ・再生速度・フリガナなどの設定は、設定画面（タイトル／本棚／本編の各画面から開けます）にまとまっています。
- 選択肢が出ると、それまでの文章は消えて直前の文章だけが残り、縦書きの選択肢が中央に表示されます。選んだ内容で物語と結末が変わります。途中で持ち物（フラグ）が付くこともあります。
- 本編の「読み返す」で、これまで読んだ文章を最初からさかのぼって読めます。めくれたページの文章も残っています。選択肢は、選んだものだけが記録されます（選ばなかったものは残りません）。
- 進行は物語ごとに自動で保存されます。閉じても、途中から再開できます。
- バッドエンドになったら「最後の選択からやり直す」で、直近の選択肢まで戻れます。手がかりや持ち物を見直して、ハッピーエンドを目指してください。
- ハッピーエンドを見た本は、本棚の表紙に小さな赤いしおり紐が付きます。
- 進行状況は、設定画面の「記録のバックアップ」からファイルに書き出し／読み込みできます。

## ファイル構成

- `src/logic.ts`: ノベルのエンジン（進行・分岐・フラグ・チェックポイント・シナリオ検証）。DOM に触れない純関数
- `src/stories/<作品ID>.ts`: シナリオデータ（作品ごとにファイルを分ける）
- `src/stories/index.ts`: 作品の一覧（作品を足すときはここに登録。本棚もこの一覧から作る）
- `src/main.ts`: 画面の操作（タイトル／本棚／本文／選択肢／結末、保存、音の再生つなぎ）
- `src/ruby.ts` / `src/furigana.ts`: フリガナ（青空文庫式「漢字《よみ》」記法）の解析と描画
- `src/narration.ts`: 読み上げ音声の再生まわり
- `src/assets/scenes/`: 背景イラスト（自作 SVG）
- `src/sound.ts` / `src/title-song.ts`: 効果音・BGM（Web Audio で合成）
- `src/storage.ts` / `src/backup.ts`: 保存とバックアップ
- `src/pwa.ts` / `src/install.ts` / `src/debug.ts` / `public/boot.js`: 更新案内、インストール案内、デバッグモード、起動失敗時の復旧
- `scripts/build-narration.mjs`: 読み上げ音声の生成・取り込み（詳細は `docs/HANDOVER.md`）
- `public/audio/<作品ID>/`: 読み上げ音声（場面ごとの MP3）
- `public/home/`: 紹介ページ

素材について: 背景は自作の SVG、効果音・BGM は Web Audio の合成音、読み上げ音声は Gemini TTS で生成したものです。外部の素材・フォント・CDN は使っていません（オフラインで動きます）。

## 開発

```bash
npm ci
npm run dev          # 開発サーバー
npm run verify       # lint → test → build → check:dist
npx playwright install chromium && npm run test:e2e
```

ルールの詳細は [CLAUDE.md](./CLAUDE.md) を、現行状態・音声制作の知識・未解決事項は [docs/HANDOVER.md](./docs/HANDOVER.md) を参照してください（AI エージェントは [AGENTS.md](./AGENTS.md) から）。

## デバッグモード

バージョンの表示を続けて 5 回タップすると、左下に操作パネル（DEBUG）が出ます（「結末」= 最後の選択肢へ飛ぶ、「最初」= 物語の最初へ）。もう一度 5 回タップするか、パネルの「終了」で消えます。パネルの操作を使った回は、到達した結末を記録しません。
