# 午前0時の校舎 ― 短編ホラーサウンドノベル

文化祭の前夜、真夜中の校舎に一人取り残された。名前を呼ばれても、返事をしてはいけない。
文章を読み進め、選択肢で物語が分岐するサウンドノベルです。選択次第でハッピーエンドにもバッドエンドにもなります（結末は全3通り）。

公開 URL（GitHub Pages）: https://mmishina-art.github.io/simple_visual_novel/
※ 公開には GitHub の Settings → Pages → Source を **GitHub Actions** にする設定が必要です（初回のみ）。

## 遊び方

- タイトル画面で「はじめから」を押すと始まります。本文（背景の上の縦書き）をタップすると文章が進みます。文章は消えずに左へ追加されていき、はみ出した分は文章の場所を横にスワイプすると読み返せます。
- 選択肢が出ると、それまでの文章は消えて、縦書きの選択肢が中央に表示されます。
- 途中で選択肢が出ます。選んだ内容で物語と結末が変わります。途中で持ち物（フラグ）が付くこともあります。
- 進行は場面ごとに自動で保存されます。閉じても、タイトル画面の「つづきから」で再開できます。
- バッドエンドになったら「最後の選択からやり直す」で、直近の選択肢まで戻れます。手がかりや持ち物を見直して、ハッピーエンドを目指してください。
- 到達した結末の数はタイトル画面に表示されます。進行状況は「記録のバックアップ」からファイルに書き出し／読み込みできます。
- 音は右上のボタンでオン／オフできます（音が出る場面があります）。

## ファイル構成

- `src/logic.ts`: ノベルのエンジン（進行・分岐・フラグ・チェックポイント・シナリオ検証）。DOM に触れない純関数
- `src/stories/midnight-school.ts`: シナリオデータ『午前0時の校舎』（作品ごとにファイルを分ける）
- `src/stories/index.ts`: 作品の一覧（作品を足すときはここに登録。将来の本棚画面もこの一覧から作る）
- `src/main.ts`: 画面の操作（タイトル／本文／選択肢／結末、保存、音の再生つなぎ）
- `src/assets/scenes/`: 背景イラスト（自作 SVG）
- `src/sound.ts`: 効果音・環境音（Web Audio で合成、音声ファイルなし）
- `src/storage.ts` / `src/backup.ts`: 保存とバックアップ
- `src/pwa.ts` / `src/install.ts` / `src/debug.ts` / `public/boot.js`: 更新案内、インストール案内、デバッグモード、起動失敗時の復旧

素材について: 背景は自作の SVG、音は Web Audio の合成音です。外部の素材・フォント・CDN は使っていません（オフラインで動きます）。

## 開発

```bash
npm ci
npm run dev          # 開発サーバー
npm run verify       # lint → test → build → check:dist
npx playwright install chromium && npm run test:e2e
```

ルールの詳細は [CLAUDE.md](./CLAUDE.md) を参照してください。

## デバッグモード

バージョンの表示（`v0.1.0`）を続けて 5 回タップすると、左下に操作パネル（DEBUG）が出ます（「結末」= 最後の選択肢へ飛ぶ、「最初」= 物語の最初へ）。もう一度 5 回タップするか、パネルの「終了」で消えます。パネルの操作を使った回は、到達した結末を記録しません。
